# 潮汐女仆 · Tidewhale

按照提供的图 2 制作的立体角色；图 1 用于核对服装和鲸鱼特征。预览均由本工程的实际网格与贴图渲染，没有把参考图贴成角色正面或预览图。

## 在 Blockbench 中编辑

1. 用 Blockbench 打开 `潮汐女仆.bbmodel`。这是自由模型工程，已经嵌入贴图，不需要插件，也不需要导入第三方模型。已在 Blockbench 5.2.2 中重新打开核对。
2. 展开 `潮汐女仆 / TIDEWHALE 01 → 01 身体 / Bodice → 03 头部 / Head → 表情 / Expressions`。先关掉当前脸的眼睛图标，再打开另一张；同一时间只显示一个表情。可选微笑、闭眼、大笑、鼓腮、困倦和惊讶。
3. 在“动画”页选择 `Tide · 潮息` 并播放。循环约 4.8 秒，头部、后发、鲸尾和双叶尾鳍轻轻摆动。
4. 发片、头饰、左右手臂、腿、围裙和鲸尾均可单独编辑。`atelier-atlas.png` 是同一张 1024 × 1024 贴图的独立副本；编辑外部 PNG 后，如要更新工程，也需要在 Blockbench 中替换其内嵌贴图。

## 文件用途

| 文件 | 用途 |
| --- | --- |
| `潮汐女仆.bbmodel` | 主工程。保留全部六种表情、22 个分组和待机动画。 |
| `Tidewhale-Maid.glb` | 通用 3D 交换版。保留微笑表情、贴图和待机动画；不含其余五张重叠的备用脸。 |
| `model-sheet.png` | 四视图、六表情预览，可对照造型。 |
| `portrait.png` | 大尺寸四分之三角度单人像。 |
| `turntable.mp4` | 6 秒静态姿势环绕展示，不是待机动画录像。 |

这里交付的是 Blockbench 自由模型，不是可以直接导入游戏的 YSM 角色包。没有改动小屋网页或模组。
