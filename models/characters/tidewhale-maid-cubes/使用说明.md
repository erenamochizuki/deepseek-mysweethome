# 潮汐女仆 · 纯方块版

打开 `潮汐女仆-纯方块.bbmodel` 即可在 Blockbench 里编辑。默认微笑贴图已内嵌；即便将工程单独移到别处，也不需要重新寻找贴图。

## 模型与视图

- 工程采用 **Bedrock Entity** 格式。从空工程重搭，并在 Blockbench 中重新打开核对：**1,395 个 Cube、0 个 Mesh、63 个分组，所有方块都有厚度**。旧网格版与第三方压缩包均未修改。
- 发梢、鲸鳍、裙褶、袖口、围裙、蝴蝶结和鲸尾均为方块。眼睛、嘴、围裙上的小蓝鲸和裙边的金绣是画在方块表面的纹理，不是悬浮的平面模型。
- `四视图.png` 的上排直接取自最终工程的 Blockbench 视窗；下排展示同一几何体的六款表情。`360展示.mp4` 是展示旋转，不是角色动画。
- `tidewhale.geo.json` 是由 Blockbench 原生导出的几何文件，配合同名 `tidewhale.png` 使用。它不是完整的游戏角色包：未附模组控制器、游戏行为或动作文件。

## 换表情

纹理面板中，右键当前的 `tidewhale.png`，使用 **更改文件 / Change File**，选择 `expressions/` 中任意一张 PNG；恢复默认微笑时选择根目录的 `tidewhale.png`。六张图的衣料、配饰和 UV 排布相同，只有脸部像素不同。若要保留切换后的版本，请将工程另存一份。

| 图集 | 表情 |
| --- | --- |
| `tidewhale.png` | 微笑（默认） |
| `02-blink.png` | 眨眼 |
| `03-laugh.png` | 欢笑 |
| `04-serious.png` | 认真 |
| `05-sleepy.png` | 困倦 |
| `06-surprise.png` | 惊讶 |
