# 潮池鱼类的 Blockbench 源件

这些 `.bbmodel` 可以直接用 Blockbench 打开，文件名对应图鉴中的鱼种 ID。网页在构建时读取源件及内嵌色板，不用另外导出贴图。每种鱼的头朝 +Z，`tail` 组的枢轴放在尾柄；动尾巴时，眼睛、鱼身和身上的纹路不会跟着扭。

这里有 17 种浅海鱼和 8 种远礁鱼。另有三种浅海鱼沿用上一级的 `rockpool_fish.bbmodel` 和各自配色；小丑鱼、蓝倒吊保留海里原有的方块造型，合计浅海 20 种、远礁 10 种。

其中 7 种有第二套花色。模型内第一张纹理是原色，`form_<花色 ID>.png` 是同坐标的另一张色板；`mark_base` 与 `mark_<花色 ID>` 子组分别装两套纹路，其余鱼身、眼睛、尾鳍共用。图鉴与海里、鱼缸使用同一套模型。构建小屋后运行 `node web/tools/fish-folio.mjs`，可从图鉴重新生成[全鱼种与花色总览](../../../docs/fish-folio.png)。
