# 海边小屋 v4 使用说明

这份本地成品包含网页小屋、方块工作台、Minecraft 模组和默认房屋鲸图。网页双击 HTML 即可打开；推荐 Edge 或 Chrome。服务模式下工作台地址为 http://127.0.0.1:5194/studio.html，小屋地址为 http://127.0.0.1:5194/cabin.html。

## 网页和编辑器

- `小鲸鱼之家.html` 是游玩页，`海边小屋.html` 提供房屋导入、摆放等调试功能。
- 打开 `工作台.html`，在模型菜单选择「方块编辑器 · P6」。可以载入默认房屋、新建空场景或导入鲸图；切换高度层后放置/删除方块、编辑状态、放置/移动/旋转整件家具。撤销/重做最多保留 80 步。
- 导出鲸图得到一张包含 Sponge v3 schematic 的 PNG，方块状态和照片数据随文件保存。编辑中的文档与游玩存档相互独立；关闭前请导出。
- 方块编辑器的详细说明见 `说明/BLOCK-EDITOR.md`。浏览器反馈上传需要工程自带服务，独立 HTML 的编辑和导出不依赖反馈服务。

## Minecraft

适用 Minecraft 26.1.2 + NeoForge 26.1.2.76，Java 25。将 `xiaojingyu-0.1.0.jar` 放入对应游戏实例的 `mods` 目录，将 `house-v4.png` 或自己导出的鲸图放入实例的 `xiaojingyu` 目录。进入世界后执行 `/xjy place house-v4`；具体命令参数可用游戏内补全查看。更新模组后需重启游戏。更新默认鲸图文件不会修改世界中已经放下的建筑。

相册桌有照片时，拆除掉落物携带一个很小的相册引用，照片本体保存在当前世界的 SavedData 中。重新放置、复制物品和重新进入同一世界均恢复独立相册；复制后修改一张桌子不会修改另一张。空桌仍为普通物品。引用丢失时会提示并拒绝放置，不消耗物品。

携带照片跨世界应使用鲸图导出/导入；不要只复制引用物品，也不要单独删除世界的相册 SavedData。备份整个世界即可保留这些照片。相册与照片框的格式见 `说明/PHOTOS.md`。

## 角色与家具互动

- 鼠标移到可交互对象上时，物体本身显示高亮轮廓，并保留手形光标和中文操作提示。被墙挡住的对象不提示；拖动镜头、移出画面、打开遮盖界面或进入布置/反馈模式时描边与提示收起。
- 沙滩上可拾取的贝壳按小花盆盆体的量级调整尺寸，保持各自造型比例，点选范围、闪光、落地与冲岸动画同步适配；已有存档中的沙滩贝壳重新打开页面也会更新。全部贝壳保留完整底面，翻滚时不会因底面被删而露空；沙钱原有的小孔保留。收藏柜和收藏图鉴继续使用展示尺寸。
- 点击小鲸鱼：她会停下当前走路或捡拾，转向镜头回应，随后恢复原来的自主行为。连续戳有短冷却；拖动镜头、布置模式、被墙挡住时不会误戳。默认模型、v1 和兼容的导入 YSM 均可用。
- 本机集成版切到「一楼」，点击书架即可打开日记日期列表，和侧边「日记本」共用同一面板。书架被遮挡或在布置、反馈模式时不会打开；独立静态 HTML 和 Minecraft 不读取本机私人日记。
- 切到「一楼」，点击电视屏幕开机；面板可以关机、切换海边/星空/天气三个频道。
- 点击电饭煲开始煮饭。游玩中等待 30 秒进入保温，点「盛到碗里」会显示米饭，「吃饭」清空碗；煮饭中可以取消。布置模式暂停计时，离线关闭页面不会自动快进。
- 点击摇椅邀请小鲸鱼走到椅前坐下，摇动约 20 秒后起身；再次点击椅子或戳她可提前结束。椅前被挡住时会提示；缺少合适腿骨的导入模型不能使用坐姿。
- 点击原版灯笼开关灯光；点击门打开控制面板，支持「打开 / 关闭 / 自动」。关门时小鲸鱼经过会临时让行，防止穿门或夹住。
- 一楼和阁楼剖视会隐藏被切掉天花板上的灯具外观，保留照明；返回「外观」恢复灯具。

电视和电饭煲按当前房屋内容、家具坐标分别保存在浏览器中，照片更换不会清空这些状态；重新布置或导入不同房屋可能重新开始。玩法状态不写入鲸图，不改变 Minecraft 家具的装饰/照片功能。

## 本轮变化

原创门、木地板和灯笼纹理已补全，默认角色眼睛恢复正常受光；外部导入角色的发光设置保留。望远镜改为 21 个带旋转的部件，网页与 Minecraft 共用模型和纹理。阵风会触发风铃音效，与人物经过共用冷却，并遵守静音、声音解锁和听觉距离设置。

按用户反馈，七种植物（花盆、蕨类、落地植物、多肉、紫色花箱、粉色花箱和吊篮）恢复到本轮简化之前的完整模型及纹理，合计 288 个部件，每格仍不超过 32 个。网页与 Minecraft 同步使用恢复版；角色、家具互动与剖视照明改进继续保留。

### 2026-11-12：三个低元素模型

- 台阶花盆 **32 → 28 个元素**，清理盆身，保留原来的花叶、贴图和碰撞边界。
- 海胆空壳 **60 个元素**，保留圆润分层、贯穿的顶孔与五条粉纹；虹彩鲍壳 **56 个元素**，保留弯曲的浅碗、四个贯穿壳孔与虹彩。网页与 MC 资源包共用几何和贴图。
- Minecraft Java 26.1.2 可单独启用三模型资源包（格式 84.0）。它只覆写原模组的花盆外观，并提供两个可用命令预览的物品模型；不安装模组也能预览两个收藏，不新增掉落或收集玩法。命令在 ZIP 的 `README.txt` 内。
- 从 `web/` 执行 `node tools/collectible-mc-pack.mjs <新路径.zip>` 构建资源包；花盆可编辑源在 [flower_pot.bbmodel](../models/furniture/flower_pot.bbmodel)，收藏的共用方盒入口在 [31-collectible-cubes.js](../web/src/31-collectible-cubes.js)。

成品中的 `manifest.json` 记录每个文件的大小和 SHA-256，便于核对复制结果。详细验收记录见工程 `docs/INTEGRATION-V4.md`。
