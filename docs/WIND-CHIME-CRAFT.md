# 自制风铃：用自己的收藏串一串风铃

状态：设计定稿（2026-11-21），按本文分批实现。分支 `codex/wind-chime-craft`。

## 0. 一句话

小屋有**两个**风铃：门上原有的那个，和新加在阁楼朝海小窗窗台上方的那个。两个都可以重新串：从收藏里挑**具体的那几枚**（带尺寸、花纹、王冠），挂到横杆下的几串线上。挂好后风铃就是你串的样子，随风摆、有人走过会响；后续每种材料还会有自己的声音。

## 2. 玩法

1. 点任意一个风铃（门上或窗边）：照旧响一串（`click-chime-crab` 测试的行为不变），同时在旁边弹出一个小菜单（样式参照救生圈的浅海菜单），里面一项「重新串一串」。菜单几秒后自己收起，不挡视线。
2. 「重新串一串」打开**这一个风铃**的工作台（HUD 弹窗，自己的 WebGLRenderer，做法同沙盘编辑器；标题写明是「门上的风铃」还是「窗边的风铃」）：
   - 上面是横杆的侧视图，下面挂几串线（固定位置，均匀分布；门上 5 串，窗边 3 串，见第 3 节）。
   - 底部抽屉：能挂的藏品，每一枚单独列出，按种类分组，看得到尺寸、花纹、王冠；已经在沙盘 / 展柜 / 借给寄居蟹 / 挂在风铃上的不出现在可选里。
   - 拖一枚到某串上就挂上（挂在这串最下面，或者落点最近的两枚之间）；点选中一枚后有按钮：上移、下移、间距 − / +、取下。拖出工作台也算取下。
   - 预览里的风铃一直在轻轻摆（和门上的同一套摆动参数），看得出长短、疏密。
   - 改动 0.5 秒后自动存档（同沙盘），失败时提示并回到存档里的样子。
   - 一键「全部取下」：这一个风铃上的藏品退回收藏，它恢复默认款。
3. 挂上去的藏品算「在用」：不能卖、不能上展柜、不能放沙盘、不能借给寄居蟹，也不能同时挂在另一个风铃上。收藏详情里显示「挂在门上的风铃」/「挂在窗边的风铃」，并能从那里直接取下（和沙盘里的一样处理）。取下后原样退回，尺寸花纹不变。
4. 风铃按设计重画：横杆 + 每串一根线，藏品按真实尺寸挂在线上，各自轻微转动；整串照旧随风摆、被走过 / 阵风 / 点击碰一下就摆。

## 3. 定下来的规则（初稿，用户可推翻）

- **两个风铃位**，各存一套设计：
  - `door`：门上方原有的风铃（格子 (−2, 3, −6)）。房子布置过时取离前门最近的 `wind_chime` 方块。
  - `window`：**新加的**，挂在阁楼朝海小窗（`40-layout` 的 `gableS`，门正上方那扇）**屋内**窗框上沿，下面是窗台。默认房子里加一个 `wind_chime` 方块（挂墙，背后是窗洞上方的墙）。房子布置过时取离这扇窗最近、且不是 `door` 的那个 `wind_chime` 方块。
  - 多出来的风铃方块（布置模式里自己加的）照旧是默认款。某个位置找不到风铃方块时，那一套设计照样保留在存档里，从收藏盒的入口仍能打开工作台，只是场景里看不到。
- **给花盆留位置**。阁楼西窗（`gableW`）有原来的贝壳展示位 `loft-window`。朝海小窗（`gableS`）上方挂风铃，整块窗台留给以后的花盆。串到最长时，风铃最低处离窗台台面至少 35 厘米，窗前仍能走动。窗铃在屋里也会随阵风摆动。
- **设计为空 = 默认款**：一个位置的所有串都空时，这个位置画原来的体素风铃。从没改过的玩家，门上那个看到、听到的都和现在一样；窗边多出的那个也是默认款的样子。
- **横杆**：P1 只有一种「漂流木横杆」（`bar: 'driftwood'`），字段留着，以后加竹节、旧船桨。
- **数量与长度**：
  - 门上：最多 5 串，每串最多 5 枚。每串总长 = Σ(间距) + Σ(该枚尺寸)，不超过 **80 厘米**（挂得下、她走过不碰头）。
  - 窗边：最多 3 串，每串最多 4 枚，每串不超过 **45 厘米**。挂满后按真实窗台台面检查花盆可用的高度。
  - 间距 2–12 厘米整数，默认 4。规则模块和编辑器都检查，编辑器里放不下的落点变红。
- **入口**：点风铃弹出的小菜单；收藏盒里加一个「风铃」入口，先选门上 / 窗边再进工作台（没有风铃方块时也能进）。
- **MC**：默认房子多出的窗边风铃方块在 MC 里也是一个普通风铃方块（默认样子，走过照样响），模组代码不改；自制设计只在网页里画。如果默认房子的方块数据要靠 `mod/` 里的工具或生成器重新生成才能加这一格，先停下来说明，不要动 `mod/`。

## 4. 数据与规则（`58-inventory-rules.js`）

```js
inventory.chimes = {
  door:   { rev: 0, bar: 'driftwood', strands: [ [ { uid, gap } ], [], [], [], [] ] },   // 固定 5 串
  window: { rev: 0, bar: 'driftwood', strands: [ [], [], [] ] },                         // 固定 3 串
}
// 每串从上往下；gap = 这一枚上方的线长（厘米，整数 2..12）。位置表（串数、每串枚数、长度上限）写成规则模块里的常量 CHIME_SLOTS，页面和服务端共用。
```

- `freshState` / `empty()` 带上默认值；`parseInventory` / `parseState` 把 `chimes` 当作**可选字段**：旧档、旧备份没有时补默认，带了就严格校验（未知位置、未知 uid → 相应错误；重复 uid（同一位置内或两个位置之间）、超长、超数 → `invalid_input`）。
- `usedUids` 加上两个风铃里的 uid。所有检查「在用」的地方（sell、place、shore 借壳、`tray_set`）都要认风铃；`tray_set` 现在自己拼了一份 placed 集合，要一并补上，最好改为统一用 `usedUids`。
- `isEmpty` 把风铃算进去（风铃里有东西就不是空存档）。
- 新命令 `chime_set`（每个位置各自有 rev，改一个不影响另一个）：

| op | 字段 | 结果 | 说明 |
| --- | --- | --- | --- |
| `chime_set` | `slot`（`door` / `window`）, `base, bar, strands, by`，可选 `via` | `{ slot, chimeRev }` | 整套替换这个位置。`base` ≠ 这个位置当前的 `rev` → 409 `chime_changed`。uid 必须是自己的，且不能在展柜 / 沙盘 / 借出 / **另一个风铃**上（`in_use`）；本来就挂在这个风铃上的可以挪位置。`via` 同 `tray_set`，只记录 |

- 页面端 `59-cabin-inventory.js` 加对应的客户端调用和错误文字；离线（浏览器本地存档）和本机服务走同一份规则。
- 更新 `docs/INVENTORY-V2.md`：数据格式表、操作表、错误码表各加一行，并提醒本机服务要随页面更新 `inventory-rules.mjs`。

## 5. 画法

- 新模块（建议 `web/src/57-wind-chime-craft.js`，在 `55-house-detail` 之后加载）提供 `V3.chimeCraft`：
  - `layout(slot, design)`：纯函数，算出每串每枚的位置（厘米，相对横杆），P1 测试直接测它；
  - `slotOf(cell)` / `cells()`：哪个风铃方块是 `door`、哪个是 `window`（纯函数部分可测）；
  - `build(slot, design)`：生成挂件组（横杆、线、各枚 `V3.shells.build` 的网格），给场景和工作台共用；
  - 场景里：`55-house-detail` 画每个风铃时问它是哪个位置，若该位置设计不为空，就把默认的体素挂串换成 `build` 的结果，骨骼（每串一根）和 `K.chimes` 的摆动、`chimeKick`、点击拾取盒照旧对得上。存档变化（`chime_set` 成功、导入备份、重置）后只重建对应的那一件，不重建整个场景。
- 窗边风铃的默认款可以就是门上那件的体素版，按窗边的尺寸缩短（串短一点），挂法用现有的挂墙规则；`66-chime-sound` 本来就按方块找风铃，第二个方块自动会响。
- 藏品挂法：每枚挂点在它模型包围盒的顶部中心（个别形状不好看的，如长条的竹蛏、象牙角贝，可给一个旋转让它竖着垂下来）；每枚绕线轻微自转，相位各不相同。
- 性能：25 枚都是现成的小网格，共用几何与材质缓存；不另加光源。

## 6. 声音（P2）

- 目录里每种能挂的藏品给一个音色 `chime`：`shell`（贝壳）、`glass`（海玻璃、玻璃浮球）、`wood`（浮木、竹节、软木塞）、`stone`（卵石、浮石、化石、海陶片）、`metal`（沉船罗盘、银帆船徽、宝藏螺等金属感的）。测试保证**每种能挂的藏品都有音色**，以后加新收藏漏了会红。
- 合成仍在 `66-chime-sound.js`，沿用解锁、静音开关、距离衰减、声像。每种音色一组参数：泛音比例、衰减、「嗒」的音量和滤波。
  - shell：现在这套，衰减略短、「嗒」略重；glass：高、近纯正弦、余音长；wood：低、短、带通噪声 + 一个低泛音，空心感；stone：闷的一下，几乎没余音；metal：不成整数倍的泛音、余音最长。
- 音高按尺寸：越大越低（在每种音色的范围内），同一枚每次音高稍有随机。
- 发声改为「碰撞」：每串是一个摆，相邻两串摆到足够近时，两串上最靠近的两枚各响一下（各用自己的音色）。走过、阵风、点击仍是触发摆动的来源；1 秒冷却、点击 0.4 秒限制照旧。默认款风铃声音不变。
- 工作台里点某一枚 / 某一串可以试听。

## 7. 她（P3）

- 对话工具 `wind_chime`（`58-cabin-tools` 登记，格式同 `sand_tray`）：指定门上或窗边，查看当前设计（文字描述 + 侧视截图）、整套替换。她通过对话串风铃时 `via` 带会话 id。更新 `docs/CABIN-TOOLS-BRIDGE.md`。
- 事件：`chime_set` 成功后发 `game:cabin-event`，type `chime_set`，detail 带件数和每串的藏品名，`by: 'player' | 'girl'`，text 如「你把一枚大金冠扇贝挂上了风铃」。（P1 就可以发，便宜。）
- 空闲行为：起风（阵风）时她偶尔走到门口抬手拨一下风铃（看海那类消遣的一个变体，给正事让路，下雨不去）。
- 第一次挂好时在相册存一张风铃特写纪念照（参照寄居蟹首次换壳的纪念照）。

**与初稿的区别及补充**

- 贝壳展品在西窗。朝海小窗只挂风铃，窗台留给花盆。默认房中，窗台台面高度为 6 米，45 厘米长的挂串最低处为 6.6275 米，实测净空 **62.75 厘米**。
- 拆到只剩一件时按它更靠近的门或窗分配。两件以上先取靠近前门的一件，再从其余方块选最靠近朝海窗的一件。
- Windows 检出会给部分 `.mcmeta` 文件使用 CRLF。家具核对工具按 JSON 文本比较其换行，保留了内容与二进制资源的检查。

**运行测试**

在 `web/` 运行 `npm test`、`npm run test:chime`、`npm run test:game`、`npm run test:furn`。单独检查两处风铃的点击路径、窗台净空和原有四个展示位可运行 `node --test test/chime-craft.test.mjs test/shell-decor.test.mjs`。本机服务要随页面更新构建生成的 `dist/inventory-rules.mjs`。

运行 `npm run test:chime-craft-browser` 会构建小屋、打开临时浏览器，并在 `web/shots/chime-craft/` 下生成 `desktop-workbench.png`、`mobile-workbench.png`、`door-default.png`、`door-custom.png`、`window-default.png`、`window-custom.png`。

## 11. P2 实现记录

门上和窗边的工作台都按当前模型的实际范围取景。挂件较少时横杆和贝壳居中放大，串变长时镜头平滑拉远。手机预览也随串长调整高度。编号、拖放高亮与镜头同步，点挂件能试听这一枚，点同串的绳段或串号可从上到下试听。试听沿用「风铃声」开关。

`30-shells.js`、`31-washup-catalog.js`、`31-moon-treasures.js` 为全部 62 种可挂藏品逐项指定 `chime`，包括 5 种超稀有宝物。扇贝等 38 种用贝壳声，2 种用玻璃声，9 种用木声，10 种用石声，3 种用金属声。软藻、空卵鞘等柔软挂件归入轻木声，矿化流木归入石声，宝藏螺归入金属声。玩家原有的挂串自动按藏品种类取音色。

`57-wind-chime-craft.js` 的 `swing` 按串长算摆速，`contact` 用同一组摆角检查相邻串的挂件。走过、阵风、点击会拨动自制风铃。挂件靠近到边缘约 1.2 厘米时，最近的一对各响一声，两枚分开后可以再次碰响。每个位置各有 1 秒冷却，主动点击按原有 0.4 秒限制。只挂一条串时也能在工作台试听。

`66-chime-sound.js` 的 `pitch` 按毫米尺寸计算基音，`materialHit` 合成一枚，`preview` 播放工作台试听。两处风铃和试听共用输出，峰值限制在满幅的 0.72 以内。默认款继续用原来的四个泛音、碰声和两三下的节奏。场景声音继续随镜头远近和左右位置变化。
