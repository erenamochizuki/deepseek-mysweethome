# 窗台小花盆：种海漂来的种子

文中验收日志和截图的路径指向本地运行测试时生成的文件。

状态：设计定稿（2026-11-21），标「初稿」的规则用户可推翻。分支 `codex/window-garden`。

## 0. 一句话

阁楼朝海小窗的窗台上放一个花盆。海浪偶尔冲上来**种子**（一类新收藏），种进花盆，每天浇水，它会按真实天数发芽、长叶、开花，开花后还能收新种子。原有的门廊盆栽、花箱、藤蔓都不动。

## 2. 玩法

1. **捡到种子**：种子和贝壳一样随潮上岸，捡起来进收藏。种子**不计入**「海滩收藏 65 种」的分母，在收藏盒里单独一栏。
2. **种下**：点窗台上的花盆 → 菜单：「种下一颗种子」（选种类）/「浇水」/「看看」/「收种子」/「换一棵」。花盆空着时只有「种下」。种下会用掉一颗种子。
3. **浇水**：每个自然日（按奖励时区）最多浇一次。当天浇过，植物这一天就长一点；没浇就停在原地，**不会枯死**。
4. **她替你浇**（初稿）：到当地 12:00 你还没浇，而且她闲着、页面开着，她会拿小喷壶上阁楼替你浇（一个短行为，给正事让路）。设置里「她帮忙浇花」开关，默认开。谁浇的都记下来。
5. **长大**：按「浇过水的天数」分阶段：
   - 第 1 天 发芽 → 第 3 天 幼苗 → 第 6 天 长叶 → 第 9 天 花苞 → 第 12 天 开花。
   - 开花后一直开着（每天不浇也不会谢）。
6. **收种子**：开花后满 3 个浇水日可以「收种子」，得 1–2 颗同种种子，植物保留，之后每满 3 个浇水日又能收一次。
7. **换一棵**：清空花盆（要确认），植物不退种子。
8. **花盆手记**：收集盒上沿新增的便签。列出 5 种植物：没捡到过的是剪影 + 线索（「雨天的潮线上常见」），种出过花的显示开花样子和一段介绍，旁边记第一次开花的日期。
9. 窗外下雨不会浇到花盆（在屋里）。积雪不影响。

## 3. 五种种子（都是真实会随海流漂流的海滨植物）

| 种子 id | 名字 | 稀有度 | 开花 |
| --- | --- | --- | --- |
| `beach_morning_glory` | 厚藤（马鞍藤）种子 | 常见 | 粉紫色喇叭花，藤会沿窗框往上爬一点 |
| `beach_bean` | 滨豇豆种子 | 常见 | 黄色小豆花，结细长豆荚 |
| `naupaka` | 草海桐种子 | 少见 | 白色「半边花」 |
| `crinum` | 文殊兰种子 | 少见 | 白色细瓣花一簇，高 |
| `sea_hibiscus` | 黄槿种子 | 稀有 | 黄色大花，花心深红（盆里长成小树苗那么高为止） |

每种种子要有拾物模型（和其他拾物同样的风格与精度），每种植物 5 个阶段的模型（发芽、幼苗两个阶段可以五种共用或微调）。植物高度要放得进窗台和窗洞，不能穿过上方风铃（见第 6 节）。种子的掉落权重、天气偏好照现有拾物的做法定，整体掉率**低**（平均几天捡到一颗），写进实现记录。

## 4. 数据与规则（`58-inventory-rules.js`）

```js
inventory.garden = {
  seeds: { [kind]: n },                        // 手里的种子数（种子不分个体，没有尺寸花纹）
  seen: [kind],                                // 捡到过的种子种类（手记用）
  bloomed: { [kind]: firstBloomAt },           // 种出过花的
  pot: null | { kind, plantedAt, watered: ['YYYY-MM-DD', ...], harvested: n, by: [...] },
}
```

- 阶段**不存**，由 `watered.length` 算（同王冠的做法）。`watered` 只留需要的长度或改存计数 + 最后浇水日，自己权衡，但要保证幂等和不能一天浇两次。
- 新命令（都带 `op`、`id`，幂等同现有）：

| op | 字段 | 说明 |
| --- | --- | --- |
| `collect` | 现有命令，`category: 'seed'` | 种子 +1，记入 `seen` |
| `garden_plant` | `kind` | 花盆空、手里有这种种子才行，扣一颗 |
| `garden_water` | `day, by` | `day` 必须是服务端按奖励时区算出的今天；今天浇过 → `applied: false` |
| `garden_harvest` | — | 开花且离上次收种满 3 个浇水日；得 1–2 颗（由 op id 决定，重放结果一样） |
| `garden_clear` | — | 清空花盆 |

- 旧档、旧备份没有 `garden` 时补空；导出导入、`restore` 带上。错误码沿用现有风格（如 `pot_busy`、`pot_empty`、`no_seed`、`not_ready`）。
- 更新 `docs/INVENTORY-V2.md` 的数据格式、操作、错误码表。

## 5. 画法与交互

- 花盆：小陶盆（风格接近门廊的陶土盆，缩小），放在阁楼朝海小窗（`40-layout` 的 `gableS`）的窗台上，靠窗台一侧；她的贝壳展示位 `loft-window` 移到另一侧或保持原位但不重叠。两样都要在窗台上看得清楚。
- 植物模型随阶段切换，加一点随风轻摆（窗边有风）。
- 花盆可点（描边、悬停照现有交互）。点了出菜单，样式参照救生圈菜单。
- 「看看」：花盆特写，可以拖动旋转（沿用模型观赏的约定：缓慢自转、可拖可缩放，不加多余按钮），显示第几天、下一阶段还差几天、今天浇过没有。
- 事件上报（`game:cabin-event`）：`garden_plant`、`garden_water`（by 你 / 她）、`garden_bloom`（第一次开花）、`garden_harvest`，text 用一句人话。

### 掉率与日期

- 每件正常潮汐拾物有 **1/432** 的机会成为种子。新存档保底的第一件仍是海滩收藏。进入种子池后，每个常见、少见、稀有种的权重各为 **7、3、1**，遇到偏好的天气乘 2.4。五种在八种天气下都有机会出现。
- 默认平均 7.5 分钟一潮，基础命中率 50%，命中平均 1.5 件。按沙滩一直有空位、潮水持续结算估算，基准天气约 **3 天一颗**，雷雨约 1.9 天，雪天约 4.3 天。沙滩已满、离线补潮上限和玩家自选设置都会影响实际等待时间。抽样测试固定随机种子，八种天气各抽 15 万件。
- 种下后先看见土，第一个浇水日发芽。第 12 个浇水日首次开花，第 15 个浇水日首次可收。晚收也只收一回，从实际收获那天再浇 3 天便可再收。换盆后保留初花记录和种子余量。
- 花盆和螃蟹共用一个奖励时区。第一次浇水或领币取小屋地点的时区，随后用存档里的值。午后帮忙按小屋当地时间判断，家中已有正事时优先做正事。

### 设计取舍

- 第二轮选择花盆在南窗居中，贝壳使用原来西窗的存档位置。文殊兰是五种里最高的，连盆约 50.5 厘米，离一米高的窗洞上沿约 49.5 厘米。模型测试在八个风向下逐种检查至少 45 厘米的净空。
- 手记中的「种子余量」独立列出手里的种子。拾到过但尚未开花的植物显示名字和线索，开出第一朵花时揭晓彩图。
- 存档额外记录可选的 `garden.zone`，让先浇花的玩家也能固定奖励时区。`watered` 和 `by` 按日一一对应，单盆最多保留 20,000 天。`harvested` 记录上次收种时累计浇过几天。

### 第二轮雕塑与实测

陶盆、托盘和薄土层共用一张网格。陶盆的曲面从排水孔延伸到外壁和卷边，浅托盘接在盆脚下。枝叶和花共用另一张网格，在土面处随风轻摆。两张网格都像海滩藏品一样用顶点色上色，相邻三角面共用顶点以保留平滑的弧度。各阶段按需生成，手记和特写复用同款模型。五种潮线种子沿用首轮的雕塑。

厚藤的花喉与五褶喇叭口连成一体，滨豇豆有旗瓣、翼瓣、龙骨瓣和下垂的细荚。草海桐的五片白瓣排在半圈里，文殊兰的三朵细瓣白花从同一花梗向外翻。黄槿有五片宽黄瓣、深红花心和突出的花柱。发芽和幼苗阶段区分文殊兰的带状嫩叶与其余植物的双子叶。
