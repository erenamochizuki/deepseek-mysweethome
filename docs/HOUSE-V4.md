## 3. 坐标

- 场景坐标和 MC 一样：+x 东，+y 上，+z 南（海那边）。沙滩面是 y = 0；格子 y = k 占 [k, k+1)。下文说「x = 5 那一列」「y = 4 那一层」都是格子。
- 鲸图 `Metadata.Xiaojingyu`：`Origin` = (−2, 0, −2)，就是台阶前面那一格；`Facing` = north（站在那里朝北看房子）。鲸图里格子 (0, 0, 0) 的场景位置 = Origin + Offset（FORMAT.md §3.2），Offset 是 (−6, 0, −15)。
- 在游戏里 `/xjy place house-v4-b`（docs/COMMANDS.md §3，转向用默认的 auto）：站的那一格就是台阶前那一格，面朝的方向就是从台阶看向房子的方向。

## 5. 门、窗、灯

- 门：南墙 x = −2 那一格（场景 x −2..−1），橡木门 `oak_door`，2 米高，朝北，关着时门板在墙外皮那一边，合页在西边（hinge=left）。下面是地梁，上面 y = 3 是白墙，两边是柱子。比 2.0（x −2.5..−1.5）往东挪了半格，这样西南窗能做 2 格宽，门两边都放得下柱子。门的上下两半都直接写进鲸图。用橡木门是因为原版的门里它上半有窗格，最像 2.0 带小窗的门（云杉、白桦、深色橡木这些门是整块的）。
- 窗：都是玻璃板 `glass_pane`。一楼的窗在 y = 2 那一层，离一楼地板 1 米到 2 米，上面还有 1 米白墙。
  - 南墙：西南窗 x −5..−4，东南窗 x 1..2，各 2 格宽；
  - 北墙：x = 0 一格；西墙、东墙：z = −8 一格；
  - 东、西山墙：屋脊下面 2 × 2 的方窗（y = 6、7，离阁楼地面 1 米；2.0 是圆窗）；
  - 门上面的小山墙：门正上方一格（y = 6，6–7 米）。
  - 玻璃板只和整块方块、别的玻璃板相连，门不算，所以门和窗之间都隔着柱子。
- 灯（都是灯笼 `lantern`，6 盏）：
  - 一楼：吊在灯梁下面 (0, 3, −12)，在餐桌上方，灯底离一楼地板约 2.1 米，人走得过去。灯梁是阁楼地板里 x = 0 那一列南北走向的一根整块原木。
  - 阁楼：吊在屋脊那排楼梯下面 (−2, 9, −11)，灯底离阁楼地面约 4.1 米。
  - 门廊：栏杆柱子上站 4 盏（两个角各一盏，台阶两边各一盏）。
  - 2.0 的吊灯和阁楼串灯换成了真灯（屋里太暗，晚上会刷怪）；家具里的串灯只是示意。门边的两盏壁灯没做。

## 6. 楼梯、楼梯口和怎么走

- 楼梯在东墙边 x = 5 那一列，4 级、每级 1 米、从北往南上（`oak_stairs`，facing=south）：y = 1、2、3、4 对应 z = −14、−13、−12、−11。楼梯下面用木板填满。最上一级（y = 4，z = −11）就在阁楼地板那一层，出口在 z = −10。
- 上楼前站的那格是 z = −15，贴着北墙。
- 楼梯口：阁楼地板在 x = 5、z −15..−12 开 4 格的洞（站的那格 + 前三级的上方，和草图时一样「站的那格 + 除最上一级以外的每一级」）。洞的西边 x = 4、y = 5 一排 4 格云杉木栅栏，北边是矮墙，南边接着最上一级。
- 上楼不碰头：站在每一级上（脚在这级台阶顶上，身子还有一半在后面那格），这两列从脚往上 1.8 米都是空的（测试里逐级查过）。净高 3 米以后，站的那格上面其实不开洞也碰不到头；照任务说明还是开 4 格，北边贴着矮墙，不会多出一格踩空的地方。
- 怎么走（测试里按格子找路，人占 1 格宽 2 格高，算上家具占位）：台阶前 → 上台阶 → 门廊 → 进门 → 往北走到厨房台面前（z = −14）→ 往东到 x = 3 → 贴着北墙往东到楼梯前那一格（5, 1, −15）→ 往南上 4 级 → 阁楼（5, 5, −11）。一共 **24 步**（不算家具、算上家具都是 24 步）。这条路用橙色虚线画在一楼平面图上。

## 7. 屋顶和屋脊盖板

- 主屋脊东西走向，东西两面墙是山墙。屋顶每格一级楼梯（45°），屋檐和山墙都伸出墙外 1 格。
- 两种木头一排一排交替：挑檐那排（y = 5）是丛林木 `jungle_stairs`，往上云杉木 `spruce_stairs`、丛林木……屋脊那两排是云杉木，像 2.0 的两色屋瓦（和草图时看到的一样）。材料小样还能换成只用一种木头。
- **屋脊盖板**：屋脊是南北两排楼梯背靠背（y = 10，z = −11 和 −12），上面各铺一排下半砖（y = 11，x 从 −8 到 7，含山墙挑檐，一共 32 块）。两色屋顶时用云杉木半砖 `spruce_slab`，单色时用同一种木头。部件叫「屋顶/屋脊盖板」。半砖的外半边下面是台阶低的那半，会留半格空隙，这是 MC 里常见的样子，用户同意这样做。
- 门上面朝海的小山墙：5 格宽（x −4..0），屋脊在门正上方，是一排下半砖（x = −2，z −8..−6，y = 8，顶 8.5 米）。它只从南坡长出来，和主屋顶相交的地方有 4 块拐角楼梯：(−4, 6, −7)、(−3, 7, −8) 是 inner_right，(0, 6, −7)、(−1, 7, −8) 是 inner_left（坐标是场景格子），其余楼梯都是直的。阁楼在小山墙下面多出一块，接着小山墙的窗。

## 9. 和 2.0 不一样的地方

- 墙是 1 格厚（2.0 是 0.25 米），所以照方案 B 屋里一样大、外面大一圈。
- 没有架高的木桩和格栅围板，房子直接坐在沙滩上；一楼地板还是 1 米高（地板那一层方块）。门廊和一楼地板一样高，从沙滩上一级台阶。
- 高度：一楼净高 2.5 → 3 米（用户选的），所以阁楼地板 3.75 → 5 米、屋檐 4.5 → 6 米；取整的：矮墙 0.75 → 1 米，屋顶伸出 0.5 → 1 格；屋脊 11.5 米（含盖板）。
- 门往东挪了半格；窗都是整格的方窗，山墙上的圆窗变成 2 × 2 的方窗。
- 楼梯从 11 小级变成 4 级（每级 1 米），楼梯口 4 格。
- 门廊：3 格深（z −6..−4），最外一排是栏杆，能走的地方 2 米（2.0 是 2.25 米）；东西各比房子宽 1 格；台阶 3 格宽，对着门，栏杆在那里断开。没有门廊顶（和 2.0 一样）。
- 吊灯和串灯换成真的灯笼。这些不做成方块（用户同意的清单）：沙滩、海、植物、花箱、毛巾、风铃、门边的壁灯、白色窗框；家具先放占位盒子。

## 17. 导入 MC 抓回来的房子（2026-11-07 web5）

在 MC 里改房子 → `/xjy capture` 抓回来 → 在游戏页导入，网页里的房子就换成改过的那栋。不用改代码、不用重新构建页面。

### 17.1 怎么用

1. 在 MC 里改房子：挪家具、拆家具、加小鲸鱼之家的家具或者别的原版方块都行。
2. 用 `/xjy capture` 抓回来（模组会按上次 `/xjy place` 的范围抓，大小、站立点、朝向都和原来那张一样；具体写法看 docs/COMMANDS.md）。抓出来的是一张 PNG（鲸图）。
3. 打开游戏页（`cabin.html` 或 `home.html`）→ 右下角「设置」→「房子」页 →「导入鲸图…」选这张图；也可以直接把图拖进页面。
4. 一两秒以后整个场景按新的房子重建：方块、走路、剖开的楼层、灯光、家具上会亮会动的东西都换成新的。时间、天气、楼层和镜头保持原样；她回到台阶前重新出场。
5. 设置里写着现在用的是哪张：名字、作者、抓的时间、文件名、导入的时间。
6. 导入的房子存在**这台电脑的这个浏览器**里（IndexedDB），下次打开游戏页还是它。浏览器存不了（比如隐私模式）时也能用，只是关掉页面以后回到原来的房子，导入时会提示。换个浏览器、换台电脑要重新导入。
7. 想回到原来的房子：「恢复原来的房子」→「确定」。浏览器里存的那张会删掉，你电脑上的图片文件不动。

图片要原图：聊天软件（微信、QQ 等）发图时常把方块数据去掉，或者转成 JPG，这时会提示「这张图里没有方块数据……请发送原图或者当文件发」。

### 17.2 导入时的检查

鲸图按**站立点 + Offset** 放进场景：站立点是台阶前那一格 (−2, 0, −2)（`V3.layout.house.stand`，和生成器的 `ORIGIN` 一样）。Metadata 里的 `Origin` 是抓的时候 MC 世界里的坐标，只做记录，网页不按它放。所以只要是站在台阶前、面朝房子抓的，在 MC 世界哪里盖的都一样。

| 情况 | 怎么办 |
|---|---|
| 读不出来（不是 PNG / .schem、没有方块数据、数据坏了） | 不换，照 V3.share 的错误说清楚（比如「聊天软件……请发送原图」）；JPG 之类会多提醒一句「聊天软件常把鲸图转成别的格式」 |
| `Facing` 不是朝北（原来的房子是面朝北抓的） | **拒绝**：「这张鲸图是面朝东抓的，这栋房子要面朝北抓」。网页不会自己把房子转过来 |
| 一个方块都没有 | 拒绝 |
| 放进来超出场地（东西 −26..26、南北 −18..40 米，高 −8..48） | 拒绝：不像是这栋房子 |
| 完全没盖到房子那块地方（外墙 x −7..7、z −16..−6） | 拒绝 |
| 大小和原来的不一样（原来 20 × 12 × 23 格） | **先问一句**，列出不一样的地方，点「还是用它」才换，「不用了」就不换 |
| Offset 和原来的不一样（原来 −9, 0, −15） | 先问一句 |
| 原来房子外墙以内的原版方块（墙、地板、屋顶……，家具不算）在这张图的同一格里还是同一种的不到 60% | 先问一句（写着对得上几成） |
| 没有小鲸鱼之家写的信息（比如 WorldEdit 存的 .schem） | 先问一句：会当成面朝北、站在台阶前抓的 |
| 里面有别的模组的方块，或者网页还不认识的小鲸鱼之家方块 | 照样换，换好后提一句「网页里画成近似的颜色块 / 可能画不出来」 |

`/xjy capture` 按上次 place 的范围抓回来的图，大小、Offset、朝向都一样，家具怎么改都不会被问（墙和屋顶基本没动，对得上的远超过 60%）。

## 18. 布置模式（2026-11-07 web6）

在游戏页（cabin / home）里直接挪、转、加、拆家具，挪整栋房子、转方向，再导出鲸图带回 MC。用户 2026-11-07 定的：在游戏页里做；家具和整栋房子都能动；增删墙、地板这些原版方块不做（留给以后的方块编辑器）；用长按拖动 + 小按钮。

### 18.1 怎么用

1. 左下角楼层切换上面的「布置」→ 进入布置模式。她停在原地，不逛、不捡贝壳、不跑去躲雷；镜头照常转（按住空地拖、滚轮 / 两指缩放）；右下角那排按钮和左上角的天气先收起来，楼层切换还在（要挪屋里的家具，先切到「一楼」「阁楼」）。上面一条：**加家具、挪房子、导出鲸图、撤销一步、放弃修改、完成**。
2. 选中家具：**长按**一件家具（大约 0.4 秒手指不动），或者**点一下**。选中的家具有一个蓝框，旁边出现一组小按钮（手机上停在屏幕下面）：
   - 中间「转向」：顺时针转 90°。转不开时会试着绕它别的格子转（2 格长的家具在墙角也转得过来）；挂墙的只在背后有墙的方向里转。
   - 上下左右四个箭头：按镜头的方向排（屏幕上的「上」= 离开镜头的那个方向），每个箭头下面写着世界方向（东 / 南 / 西 / 北）。一次挪一格；同一层放不下时会试试低一格、高一格（门廊 ↔ 沙滩）。
   - 「放回原处」：回到这次进布置模式时它在的地方（刚加的家具没有原处）。
   - 「拆掉」：整件拆掉（多格的一起拆）。
   - 键盘：方向键挪（和箭头一样按镜头方向）、R 转、Delete 拆、Esc 取消选中、Ctrl+Z 撤销一步。
3. **拖**：按住选中的家具直接拖；没选中的长按一下就拖起来。家具贴着格子走，指着哪里就落到哪里的地面上（一楼、阁楼、门廊、沙滩都行）；挂墙的指着哪面墙就贴到哪面墙上，自己转过来朝外；串灯指着屋脊、楼板的下面。拖的时候原来那件先藏起来，看到的是半透明的预览：放得下是蓝框，放不下是红框，指针旁边写着为什么；在红的地方松手，家具回原位。
4. **加家具**：「加家具」打开清单：41 种，分「屋里」「屋外」两页，每种一张小图（第一次打开时现画）。点一种，它就跟着鼠标走（半透明，正面朝着镜头），点一个地方放下；手机上直接点要放的地方。下面的小条可以「转向」或「取消」。放好以后它就是选中的，可以接着挪、转。
   - **相框**（2026-11-08 加的，「屋里」那页最后一个）：和画框一样挂墙，想挂几个挂几个。选中相框或者画框墙时，小按钮下面多一个「**换照片**」：从相册里挑一张挂上，或者「空」（算一步，能撤销，「完成」才存）。挪、转、拆相框和相册矮桌，挪 / 转整栋房子，照片都跟着方块走。相册怎么加照片、游戏里点相框换照片见 docs/PHOTOS.md 第 5 节。
5. 每改一下，整个场景按新的方块重建一次（测试机上约 0.2 秒），会亮会动的东西（屏幕、灯泡、灯罩和点光、风铃、遮阳伞、贝壳柜的格子）和走路都跟着方块走。
6. 「撤销一步」一步一步往回退，可以一直退到进来时。「放弃修改」：有改动时点第一下变成「确定放弃？」，3 秒内再点一下就回到进来时的样子。
7. 「**完成**」：存成「布置过的房子」，存在这台电脑的浏览器里（IndexedDB，和导入的房子一样只留一份，下次打开还是它）。设置「房子」页写着「现在用的是布置过的房子」。「恢复原来的房子」照样能用：布置过的那栋从浏览器里删掉，回到内嵌的原来那栋。没有改动时「完成」只是退出。

### 18.2 放得下的规则

一件家具放得下，**每一格**都要：

- 在房子鲸图的范围里。默认房子是东西 −11..9、南北 −17..6 米（包住房子、门廊和沙滩休闲角那一块）。鲸图外面放不了：导出的鲸图大小、Offset 要和原来一样，`/xjy place` 才盖得回原样。
- 是空的：空气，或者草、蕨、枯灌木、雪片、海草、藤蔓这类能替换的（放下去就替换掉）。挪的时候它自己原来那几格算空的。
- 不压石头、沙丘（这一格里的地面比格子底高出 0.3 米以上），不压椰子树干。

再按放法（家具规格 `V3.furnMc` 的 `mount`，FURNITURE.md 第 7 节）：

| 放法 | 哪些 | 要求 |
|---|---|---|
| 放地上（不写 mount 的都是） | 床、桌椅、柜子、地毯、地垫、盆栽、沙滩椅、遮阳伞、木箱、花箱、吊篮…… | 最下面一层每格下面要托得住：整块方块、上半砖、栅栏 / 栏杆的柱头（门廊栏杆上的多肉、吊篮就是这样放的），或者平的干沙。楼梯、下半砖、门、灯笼、玻璃板上面放不稳；湿沙不行；**家具不叠在家具上** |
| 挂墙（`wall`） | 调料罐架、画框、毛巾挂钩、贝壳风铃、门边壁灯 | 每格背后（正面反方向那一格）要是墙：整块的方块；窗户、门、栏杆、楼梯、半砖不算 |
| 吊顶（`ceiling`） | 串灯 | 每格上面要有方块（屋脊、横梁、楼板） |

- 多格的家具每一格都要满足（比如画框 2 格，两格背后都要是墙）。
- 默认房子里每一件家具在原地都符合这些规则（测试查过）。
- 不管她走不走得过去：把门口堵上也让放（MC 里也能），那样她就进不了屋。

### 18.3 导出鲸图，带回 MC

1. 布置模式上面的「导出鲸图」，或者设置「房子」页的「导出鲸图」：下载一张 PNG，文件名像 `小鲸鱼之家-布置过-2026-11-07-1530.png`（没布置过的是 `小鲸鱼之家-日期-时分.png`）。图上是点按钮时的画面，方块数据在 PNG 里（FORMAT.md）。
2. 里面的方块是**房子自己的方向**：`Facing` 北、`Offset` 和原来一样（默认房子 −9, 0, −15），大小也一样；房子在网页沙滩上挪过、转过都不影响（MC 那边不管它在网页里的位置）。Metadata：`Name` 是原来的名字加「（网页里布置过）」，`Author` 照抄，`Date` 是导出的时间，`Xiaojingyu` 里 `FormatVersion` 1、`Facing`、`Origin`（照抄原来的，只做记录）、`Source` 是 `haibian-web/…`；`FromPlace` 去掉（已经不是「按上次 place 抓回来的原样」了）。
3. 放进 MC 游戏目录的 `xiaojingyu` 文件夹（一般是 `.minecraft/xiaojingyu`；启动器开了版本隔离就是 `.minecraft/versions/<版本>/xiaojingyu`）。
4. 在 MC 里站在要当「台阶前那一格」的地方，面朝要盖房子的方向，输入 `/xjy place "小鲸鱼之家-布置过-2026-11-07-1530"`（中文名要用英文双引号；Tab 能补全），盖出来和网页里一样（要装小鲸鱼之家模组）。之前在同一个地方 place 过原来那张的话，站在同一格、同一个朝向再 place 就是在原地换掉。
5. 再导入回网页（设置「房子」页「导入鲸图」或者拖进页面）：不用问，方块逐格一样（测试查过）。导入的房子摆在原来的位置（挪房子的摆法只存在浏览器里，不写进鲸图）。

### 18.4 挪整栋房子、转方向

- 「挪房子」（或者在挪家具时长按墙、屋顶）→ 选中整栋房子，蓝框框住鲸图里有方块的那一块。小按钮：四个箭头一格一格挪、「转向」顺时针转 90°、「放回原处」回到原来的位置和方向；也可以按住房子拖（按指针在沙地上走了几格挪几格，松手时放得下才挪）。点上面的「挪家具」回去挪家具。
- 转的中心是房子外墙的中心 (0, −11)。原地转不开（会出场地、压到东西）时，自动找 8 格以内最近一个转得开的地方，挪过去再转，并且说一声往哪儿挪了几格。
- **跟着房子动的**：整张鲸图（墙、屋顶、家具，方块的朝向跟着转）、墙上的藤蔓（58-plants，门窗让洞跟着）、她出场的地方（台阶前）、门内外落脚点、她躲雷时坐的门廊沿、走路网格（门廊、一楼、阁楼）、剖开的楼层、屋顶上的雨（54-wx 先把点转回房子自己的方向再算）。她站在房子那一块里（门廊、屋里、台阶前）时，跟着房子一起挪、一起转。
- **不动的**：椰子树、石堆、礁石、海、沙丘、沙滩上的爬藤。挪过去放不下的，框变红、说明原因，不挪：
  - 出场地（场地四边各留 1 米）；
  - 有方块的地方压到湿沙或者海里；
  - 压到石堆、礁石、沙丘（地不平）；
  - 压到椰子树干；
  - 贴着地面的方块（门廊、台阶、沙滩上的家具）压到沙滩上的爬藤。
- **地形**：沙滩本来就几乎全是平的干沙（只有 3 个小沙丘、石堆、礁石不平），所以不另外压平，房子只能挪到平的干沙上（等于「只能在已经平的地方挪」）。地形在房子下面没有专门压平过的一块（52-terrain 的压平只管沙丘），所以也没有要跟着挪的。
- **能挪的范围**（默认房子、家具没动时；鲸图包住了沙滩休闲角，所以范围不大）：朝南（原来的方向）东西各能挪 1 格、往南 0..2 格（西边是椰子树和石堆，东边是爬藤，北边就是场地边）；转 90°（门朝西）要往南挪 5..6 格、往东 1..4 格；转 270°（门朝东）往南 3..6 格、往西 1..2 格；转 180° 哪儿都放不下（沙滩休闲角跟着转到房子北边就出场地了）。家具挪动、拆掉以后范围会变（比如拆了沙滩休闲角就能转 180°）。
- 存：摆在哪儿、朝哪（往东 / 往南几格、转了几个 90°）和方块一起存在浏览器里，重开还在。导出的鲸图还是房子自己的方向（18.3）。

### 18.5 已知的、没做的
