# 小鲸鱼模型：现在是什么格式，以及如果改成导入，对模型有什么要求

## 现在的模型
现在的小鲸鱼**没有模型文件，也就谈不上格式**。每次打开页面时，由代码现场生成：
- 身体：在 2 cm 的格子里一格一格地堆小方块（类似 MagicaVoxel），再转成三角面。代码在 src/20-girl.js，头部重做试验在 src/22-head2.js。
- 骨骼：11 根，分别是 胯、胸、头、左右手臂、左右腿、后发、尾巴三节。动作都由代码驱动。
- 脸：一张 64×40 像素的贴图，有 9 种表情，眨眼和说话张嘴也是代码画的（src/21-girl-face.js）。
- 想改造型只能改代码，每改一次都要重新出图对比，所以进度慢。

## 如果改成导入，对模型的要求
**文件格式**
- 首选 **.glb**（glTF 2.0）。Blockbench、Blender、VRoid（它导出的 .vrm 本身也是 glTF）都能导出这种格式。我会在 vendor/ 里加一份同版本（r152）的 three.js GLTFLoader。
- 也可以用 **.vox**（MagicaVoxel）。这种格式只有方块、没有骨骼，所以每个部件要放在单独的图层里，图层名就是部件名。每个部件的转轴我在代码里定。
- .fbx、.blend、.pmx（MMD）这些格式请先转成 .glb。

**尺寸和朝向**
- 站着高约 1.2–1.3 m（单位用米，或者告诉我比例）。
- 脚底在原点，Y 轴朝上，脸朝 +Z（glTF 默认的前方）。

**面数、贴图和材质**
- 整个角色不超过 3 万个三角面。
- 贴图不超过 1024×1024。像素风贴图我会用最近邻采样，不会被模糊。颜色用顶点色或调色板贴图都可以。
- 材质只要普通颜色或贴图，我会统一换成场景里的光照材质。除了脸以外不要有半透明。

**部件要分开并命名**（反馈工具靠名字点选部件）

| 部位 | 部件名 |
| --- | --- |
| 头 | 刘海、侧发、后发、头顶头发、呆毛、鲸鳍耳、头饰、蝴蝶结、脸、脖子 |
| 身体 | 领子、领结、上衣、纽扣、泡泡袖、袖口、手 |
| 裙子 | 围裙、鲸鱼图案、裙摆、金色刺绣、衬裙、背后蝴蝶结 |
| 腿 | 袜子、鞋、鞋扣 |
| 尾巴 | 尾巴、尾鳍 |

名字用中文或英文都行，对得上就可以。

**骨骼**（让她能动）
- 至少要有：胯 hips、胸 chest、脖子 neck、头 head；左右各一套 上臂 / 前臂 / 手、大腿 / 小腿 / 脚。
- 另外还要：尾巴三节 tail1–3、后发 hairBack、呆毛 ahoge、左右鳍耳 finL / finR，裙摆 skirt 可选。
- 方块模型可以把每块直接挂在骨骼下面（刚性绑定）。平滑模型需要蒙皮权重。VRM 自带标准人形骨骼，可以直接用。

**脸和表情**（最影响可不可爱）
- 首选：脸是一块单独的平面，或者在贴图上占一块单独的区域。我把现在的 9 种像素表情贴上去，眨眼和张嘴由代码画。
- 也可以用 blendshape（形态键）：眨眼、a/i/u/e/o 五个口型、开心 / 生气 / 困倦。VRM 的标准表情就是这一套。

**动画**（可以不给）
- 不给也行，我按骨骼用代码做这些动作：走、跑、坐、睡、游泳、蹚水、弯腰捡贝壳、挥手、看书、打字、画画、做饭、摇椅、开门。
- 如果给，请放在同一个 .glb 里，用这些名字：idle walk run sit sleep swim wade pickup wave read type draw cook rock door。

**授权**
- 原设计（whale-girl-sheet，作者 上善无形 / ZipZipPipe）用的是 CC BY-NC-SA 4.0：只能非商用，要署名，改编作品也要用同一协议。
- 买模型或找人做，要先讲清这一点。用模型网站上别人的模型，要看它自己的授权允不允许这样改。
