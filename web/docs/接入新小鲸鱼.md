# 接入新小鲸鱼（给做模型的会话）

（最初写这份文档时）游戏页 `cabin.html` 里的小鲸鱼用的是**旧版模型占位**（`src/20-girl.js` 的 `V3.girl.build()`）。走路、捡贝壳、说话、撑伞、躲雷这些行为都在 `src/65-girl-actor.js` 里，跟模型是分开的。换新模型时只需要改 `makeBody()` 和场景部件 `build()` 开头的存在检查，行为代码不用动。（下面提到的行号是当时的，代码后来改过，以函数名为准。）

这份文档写的是：新模型要提供什么、换的时候改哪几个数、怎么截图验收。

> **2026-11-05 第9轮：默认的小鲸鱼换成 YSM 模型「蓝色大肥鱼」**（用户买下的，作者同意修改并打包；详见 `docs/YSM.md` 开头）。
> - 打包：`assets/girl/fatfish-1.2.zip`，`build.mjs` 把 `assets/` 内联进页面。id `builtin:fatfish`，没选过角色时就是它。
> - 接法：`91-cabin` 开场景前 `V3.ysmUI.preload()` 把选中的模型读好 → girl-actor 建场景时 `V3.ysmUI.initialBody()` 直接用它（读不好才先用 v1，之后 `useBody` 换）。设置「角色」页可换 v1 小鲸鱼或导入的模型。
> - YSM 身体比第 2 节多给 actor 这些（都可选）：`setWeather(w, wet)`、`umbrellaArm(h)` + `umbUp`（伞杆最多斜多少）、`headTop`（头骨骼局部的头顶，对话框和伞尖用）、`longIdle`（秒：闲逛后偶尔站这么久）、`states.expr` 按 `tune.face` 换脸。
> - 验收：默认就是她、站久了演铁盆待机动画、下雨撑伞、躲雷「害怕」脸、说话嘴动、对话框在头顶上方。

> **2026-11-05 更新：游戏里已经换成 v1 小鲸鱼**（用户选的：旧工程里的长方体小鲸鱼，带 33 个动作）。
> - 模型文件：
>   - `src/09-cuboid.js`：长方体模型引擎，移植自 v1 的 05-model.js，以后 YSM 导入也用它；
>   - `src/20-girlv1.js`：造型 + 下面第 2 节的接口；
>   - `src/20-girlv1-anim.js`：33 个动作 + 呼吸 / 尾巴 / 头发跟随；
>   - `src/20-girlv1-face.js`：像素脸，会眨眼、说话张嘴。
>   - 工作台里是模型「小鲸鱼 v1（旧工程移植）」，能逐个播动作片段、换衣服和鞋。
> - `makeBody()` 先用 `V3.girlv1.build()`，出错退回旧版 `V3.girl.build()`。第 3 节那几个数不再写死，由模型自己给：
>   - `leg` / `swing`：算步幅和 RATE；
>   - `handBone` + `handOff`：右手心，伞柄和贝壳起飞点；
>   - `umbArm` / `umbFore`：撑伞的手臂姿势。
>   - REACH 由 makeBody 实测：先把她摆成蹲下伸手的样子，量出手在哪，再决定她站多远、身子往哪边偏，手才落在贝壳上。实测手离贝壳约 5 cm。
> - 姿势：stand = idle，walk = walk（动画时钟按 0.6 s 一个来回对齐脚印），pickup = pickHold，cheer = 循环的 hop，huddle = 坐在门廊沿上抱着手发抖。表情：happy → v1 的 neutral（加一点腮红），laugh / surprised / neutral / pout 同名，talk = 说话张嘴。眨眼由脸自己管（没有 inst._f）。
> - 开销：4,350 三角面、44 次绘制（每个部件一张小贴图；需要的话可以合并）。
> - 验收截图：`test/tmp-girlv1/`（cabin、wx、seat、pick）。
> - **也能换成导入的 YSM 模型**（游戏设置 →「角色」，见 `docs/YSM.md`）：`V3.actor.useBody(id, builder)` 玩着也能换。导入的模型带 `noOverlay`（不叠加第 2 节那些骨骼调整）、`setLook(yaw, up)`（头由模型自己转）、`noUmbrella`（第9轮起只有没有 `RightArm` 的模型才带，其余用 `umbrellaArm` 撑伞）、`setWeather(w, wet)`（actor 每帧告诉它天气：0 晴 / 1 雨 / 2 雷雨，wet = 正淋着雨，到了门廊板上就不算）。
> - **11-05 修：走路时腿不动**（用户反馈）。原因在 `09-cuboid.js` 的 `play(null)`：层已经在淡出时再叫一次会重新开始淡出，而 `20-girlv1.js` 每帧都叫，makeBody 量伸手位置时留在第 1 层的蹲姿就一直淡不掉，整个身子被它拖着，走路摆腿几乎被抹平。现在对已停 / 正在淡出的层是空操作（`fade: 0` 时立刻清掉）；`dt = 0`（量尺寸、换身体、暂停）时切姿势直接切过去。实测走路两条大腿 ±28° 交替，捡贝壳 / 欢呼 / 缩着坐的过渡正常。

## 1. 现在的接法

```
50-scene（house2）→ girl-actor 部件 build → makeBody() → 把 body.root 放进场景
每帧：brain（想做什么）→ move（走路、算高度）→ drive（把姿势和表情写进模型）→ inst.update(dt, a.anim)
```

`makeBody()` 返回 `{ inst, root, headBone, headTop, height }`：
- `root`：actor 自己的 Group，每帧设它的 position（脚底的世界坐标）和 rotation.y（朝向）。
- `inst`：模型实例，要求见下一节。
- `headBone` + `headTop`：头骨骼，以及头骨骼局部坐标里的头顶中心。对话框锚点 = 头顶 + 0.15 m。
- `height`：整个模型的高度（米）。

## 2. 新模型的 inst 要提供什么

旧版 `V3.girl.build()` 的接口，新模型照着做最省事；也可以写一个适配层，把 glb 节点映射成下面这些字段。

| 字段 | 要求 |
| --- | --- |
| `inst.root` | Object3D。原点在两脚中间的地面上，+Y 向上，脸朝 +Z，单位米。旧版身高约 1.26 m（头顶 y ≈ 1.26），新版在 1.2–1.3 m 之间不用改别的数。 |
| `inst.bones` | 按名字取的骨骼表。actor 直接用到 `hips`、`chest`、`head`、`armR`、`armL`、`legR`、`legL`，每根骨骼要有 `userData.rest`（静止时的 position，Vector3）。其他骨骼（尾巴、后发、呆毛、鳍耳、裙子）actor 不碰，由模型自己的 update 动。 |
| `inst.states.pose.value` | actor 每帧写入：`'stand'` `'walk'` `'pickup'` `'cheer'` `'huddle'`。工作台里另有 `'wave'` `'tpose'`，actor 不用。 |
| `inst.poseK` | 0..1，actor 写入，是 pickup / cheer / huddle 从站立过渡过去的程度（已经平滑过）。模型的姿势要按它插值，`poseK == null` 时当 1。 |
| `inst.states.expr.value` | actor 每帧写入：`'happy'` `'laugh'` `'surprised'` `'neutral'` `'pout'` `'talk'`。这些都是 `V3.girlFace` 9 种表情里的名字，新表情系统要能认这几个。 |
| `inst._f`（可选） | 眨眼计时器 `{ next, blink }`。有它的话 actor 会把 `next` 设成 1e9，停掉模型自己的眨眼，改由 actor 写 `blink`（0 睁，1 半闭，2 闭）。没有就让模型自己眨。 |
| `inst.update(dt, t)` | 每帧由 actor 调用。必须先把所有骨骼复位（rotation 归零，position = rest），再按 pose / poseK / expr 摆姿势。`t` 是 actor 的动画时钟，走路时会按步速加快。 |
| `inst.dispose()` | 释放几何体、材质、贴图。 |
| `inst.face.mesh`（可选） | 脸的网格。actor 会给它设 `userData.anchor`（没有的话设成 `'girl:face'`）和 `userData.noShadow = true`。 |

actor 在 `inst.update()` **之后**再往骨骼上叠加旋转，所以骨骼的静止旋转要是 0，轴向要和旧版一样：
- `head.rotation.y` += 左右张望；`head.rotation.x` 减小 = 抬头（下雨时看天），增大 = 低头（闪电时缩一下）。
- `chest.rotation.x` 增大 = 往前倾（跑步）；`chest.rotation.z` = 发抖。
- 起步和停下时，`legR/legL/armR/armL.rotation.x` 和 `hips.position.y` 的摆幅会乘上速度系数。
- 撑伞时 `armR.rotation` 被改成举手（x ≈ −1.0，z ≈ 0.35）。

## 3. 换模型时要重新量的数（都在 65-girl-actor.js）

| 常量 | 位置 | 意思 |
| --- | --- | --- |
| `LEG = 0.28`、`SWING = 0.45` | 第 14 行 | 胯到脚底的长度、走路时腿的摆幅。第 15–16 行由它们算一步多长和动画时钟要加快几倍，脚才不打滑。公式假设腿按 `sin(t·6)` 摆；新模型的走路不是这样摆的话，`RATE` 要跟着改。 |
| `SPEED`、`RAIN_SPEED`、`RUN_SPEED`、`CLIMB_SPEED` | 第 12–13 行 | 走 1.0、撑伞 0.7、跑 1.5、上台阶 0.8（m/s）。 |
| `HAND = (−0.03, −0.2, 0.01)` | 第 340 行 | 右手拳头在 `armR` 骨骼局部坐标里的位置。贝壳飞进收集盒时从这里起飞，伞柄也握在这里。 |
| `REACH = 0.3` | 第 224 行 | 蹲下捡东西时手在胯前面多远，决定她停在离贝壳多远的地方。 |
| `UMB_TOP`、`umbrella()` | 第 568–593 行 | 伞杆从手指向头顶上方。头更大或手臂更长时要调举手角度和 `UMB_TOP`。 |
| `seat()` | 第 478 行起 | 打雷时坐在门廊沿上：root 放在沿外 4 cm，腿垂到第一级台阶前。和 `huddle` 姿势一起按新模型的腿长调。 |
| `RAMP` | 第 82 行 | 各个姿势进入 / 退出要几秒。 |
| `EXPR` | 第 329 行 | 说话情绪 → 表情：happy→laugh、surprise→surprised、think→neutral、sad→pout。 |
| `headTop` | 第 76–77 行 | 现在取头骨骼包围盒的顶。呆毛很高的话，对话框会跟着变高，可以改成量头发顶。 |

## 4. 换的步骤

1. 在工作台里把全身模型做好，先注册成一个新模型（例如 `girl4`），在工作台里把上面的每个 pose 和 expr 都切一遍，看动作对不对。
2. 改 `makeBody()`：先试新模型，出错再退回旧版，这样新模型有问题时游戏页也不会坏。例如：
   ```js
   let inst;
   try { inst = V3.girl4.build(); } catch (e) { V3.err('girl-actor: girl4 失败，用旧版 ' + e); inst = V3.girl.build(); }
   ```
   第 599 行的检查也改成「新旧有一个就行」。
3. 按第 3 节重新量 `LEG`、`HAND`、`REACH`、伞和坐姿，再按第 6 节截图。
4. 打开 `cabin.html?fb=1`（或者点游戏页右下角的「反馈」），确认每个部位都能点中，再请用户在游戏页里反馈。
5. 可选：现在所有编号小于 90 的源文件都会打进 `dist/cabin.html`，包括 girl3/girl4 的编辑器和旧资源（23–29 号），页面约 3.9 MB。接好以后可以在 `build.mjs` 的 PAGES 里给 cabin 加一个排除列表（需要先给 build.mjs 加这个功能），只留下游戏要用的模型。

## 5. 场景里的约定

- 部位路径用 `小鲸鱼/…`，反馈工具的部位树按它分组，换场景时 `50-scene` 也会清掉这个前缀的部位。
- 每个网格要有唯一的 `userData.anchor`（旧版是 `'girl:<骨骼名>'`），反馈的大头针靠它找回位置。
- `makeBody()` 会把所有网格设成 `userData.layer = 'site'`，切楼层时她不会被藏掉。
- 默认投影子（脸除外），不要加点光源（场景里的点光源已经用了 7/8 个）。
- 预算：旧版 28.6k 三角面、12 次绘制，下雨带伞 35.2k / 14。新版尽量在 30k 三角面、12 次绘制以内；网格越少越好，同材质的部件可以合并。
- house2 打开了 solo 合并：只有当一个网格的材质数组里**全是同一个材质**时，才会把数组合成一个。运行时要单独替换 `material[i]` 的网格（例如表情、编辑器高亮），不要做成「数组里全是同一个材质」。

## 6. 验收截图

```
node tools/shoot.mjs --page cabin --w 1280 --h 800 --gpu d3d11 --wait 1500 --out test/tmp-girl/cabin --views "time=golden+weather=clear+girl=at_2_3_0+cam=2_1.3_6.5_2_0.7_3+ui=0,girl=pickup,girl=cheer,say=你好呀,hero+wash=3+beachSettle+girl=collect"
node tools/shoot.mjs --page cabin --w 1280 --h 800 --gpu d3d11 --wait 4000 --out test/tmp-girl/wx --views "hero+time=noon+weather=rain+wxfx=off+girl=wander+ui=0,hero+weather=storm+girl=shelter+wxfx=storm:1:bolt"
node tools/montage.mjs test/tmp-girl/sheet.jpg 640 400 4 test/tmp-girl/cabin test/tmp-girl/wx
```

`girl=` 的用法：`at_x_z[_朝向]` 瞬移（朝向 0 = 脸朝 +Z，也就是朝海），`x_z` 走过去，`collect` 马上去捡最近的贝壳，`wander` / `idle` / `auto`，`pickup` / `cheer` 摆姿势，`shelter` 直接坐到门廊沿上。同一次 shoot 里前面的 token 会带到后面的视角。

逐条看：
- 脚贴着沙子，不浮空、不陷进去；走路时脚不打滑。
- 蹲下时手在贝壳旁边，贝壳从手边飞向收集盒。
- 对话框在头顶上方，不挡脸。
- 伞柄在右手里，伞面在头顶上方。
- 坐在门廊沿上时腿不插进台阶。
- 表情会切换，说话时嘴会动，会眨眼；尾巴、后发、呆毛会动。
- `cabin.html?fb=1` 里每个部位都能点中；截图输出 `[__errors] none`。

## 7. 第⑤阶段已经留好的接口

- **进屋：** `V3.nav.setDoor(true)` 打开门以后，屋里也能走（`doorLink` 是门内外两个点）。actor 里躲雷的 `shelterStart()` / `seat()` 可以改成进屋。
- **睡觉：** 床的状态 `V3.furn.setVariant('bed', 'sleeping')` 是盖着人的被子；枕头上的睡帽是 `furn:bed` 下的 `bed-nightcap`，戴上时把它藏起来，再用 `V3.furn.buildNightcap({ width })` 做一顶挂到头骨骼上（原点在帽口，+Y 向上，+Z 朝前）。
- **摇椅：** `furn:rocking` 下的 `rock` 节点绕本地 x 轴摆。
- **第⑤阶段新模型还要的动作：** sit、sleep、swim、wade、read、type、draw、cook、rock、door（名字和 `docs/MODEL-IMPORT.md` 一致）。
