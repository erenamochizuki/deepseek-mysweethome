# v4 使用说明

## 打开工作台
1. 双击 `启动工作台.bat`。它会先构建，再开服务器（端口 5194），然后自动打开浏览器 http://127.0.0.1:5194/studio.html 。
2. 用完关掉那个黑窗口，服务器就停了。
3. 不开服务器也能用：直接双击 `dist/studio.html`。这时反馈存在浏览器里（右上角显示「离线模式」），之后点「导出」存成文件给我；下次开着服务器打开时，也可以点「上传 N 条离线反馈」。

## 写反馈
1. 鼠标停在模型上，会提示这一块叫什么（比如「小鲸鱼 / 头 / 刘海」）。
2. 点一下就选中这一块，弹出反馈框。再点同一块里更细的地方，会选到更细的部位；按 `[` 回到上一级。
3. 选一个类别（形状 / 颜色 / 比例 / 位置 / 动作 / 材质 / 缺失 / 其他）和程度（小 / 中 / 大），写一句话，按 Ctrl+Enter 或「提交」。
4. 提交时会自动截图，并记下部位、镜头角度、点的位置、当时的表情和动作。我读文件就能看到你看到的画面。
5. 左边的部位树可以搜索、隐藏某一块、「只看这个」。被挡住的地方（比如头发后面的身体）先隐藏头发再点。

## 看我改好了没有
- 右边是反馈列表。我改完会标「已修复」并写一句回复。
- 你看过觉得好了，点「确认解决」；还不对，点「还有问题」再写一句。
- 点列表里的一条，镜头会回到你当时提交的角度。

## 2D 反馈（在参考图上回答问题）
1. 工作台左边最上面有「3D 反馈 | 2D 反馈」。点「2D 反馈」，右边换成参考图标注页；点「3D 反馈」回来，模型、镜头、选中的部位都和走之前一样。
2. 左边「项目」里选要答的项目（`refs/` 下的文件夹）；「新项目」建一个新的。
3. 把截图拖进来、Ctrl+V 粘贴，或点「上传」。我看过图会在右边提问。
4. 回答右边的问题，核对图上的框：虚线框是我猜的，对就点「对，确认」，不对就改种类或删掉；漏了的在图上空白处拖一个。改动会自动保存到 `refs/<项目>/answers.json`。
5. 答完点右上角「这轮答完了」，回聊天说一声。
- 要用 ← → 换图、1–7 改框的种类、Delete 删框，先在标注页上点一下。这时 3D 的快捷键不起作用。
- 要开着服务才能用（双击 `启动工作台.bat`）；直接双击 `dist/studio.html` 时只会提示这一点。
- 详细说明在 `tools/refkit/GUIDE.md`。示例：项目 `scene-01`，三轮都答完的 MyGO 场景（截图只在本机用，见 `demos/mygo-scene-01/README.md`）。

## 常用按键
左键拖动 = 转镜头，右键 / Shift+拖动 = 平移，滚轮 = 缩放，双击 / F = 对准选中部位，H = 隐藏，I = 只看这个，Shift+H = 全部显示，1–9 = 当前模型的视角（小鲸鱼：正面 / 侧面 / 背面 / 3/4 / 脸部；小屋 2.0：主视角 / 小岛 / 正面 / 小屋 / 一楼室内 / 阁楼 / 俯视 / 全景 / 看太阳），空格 = 暂停动画，Esc = 关闭 / 取消选中。工作台右上角的「?」里也有。

## 游戏页（海边小屋）
1. 双击 `启动小屋.bat`。服务器已经开着时，它只会打开 http://127.0.0.1:5194/cabin.html ；没开时会先开服务器（关掉黑窗口就停）。
2. 贝壳和海螺会被浪冲上岸。点一下就收进右下角的收集盒；小鲸鱼闲着也会自己去捡。
3. 右下角三个按钮：
   - **收集盒**：右上角的数字是找到了几种（共 12 种）。没找到的显示灰色剪影，点开一种能转着看，还有第一次找到的时间和一共找到几个。点阁楼的贝壳柜也能打开。
   - **设置**：「海边」页调冲上岸的间隔、几率、每次几个、沙滩上最多几个、三档稀有度的权重，以及小鲸鱼会不会自己去捡、隔多久去捡，还有「现在就冲一波」按钮；「天气」页选实时天气或手动天气。
   - **反馈**：打开反馈工具，用法和工作台一样，再点一次关掉。
4. 左下角：外观 / 一楼 / 阁楼，切换看屋外还是屋里。
5. 左上角是天气小卡片，点它直接打开设置的「天气」页。
6. 进度存在浏览器里。设置里的「清空收集」会从头开始。

## 文件在哪
- 反馈：`feedback/items/*.json`，截图 `feedback/shots/*.png`。
- 2D 反馈：`refs/<项目>/`，截图在 `images/`，回答在 `answers.json`。
- 我这边看反馈的命令：`node tools/fb.mjs list`（详见 docs/TOOLS.md）。
- v4 的网页部分全部在本文件夹里，删掉不影响 v3 和旧版 v1。
