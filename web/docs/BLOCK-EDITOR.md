# P6 工作台方块编辑器

入口是工作台 `studio.html` 顶栏的「方块编辑器」按钮或模型下拉的「方块编辑器 · P6」。也可直接打开 `studio.html?model=blockeditor`。游戏页的家具布置是另一项功能；本编辑器仅打包进工作台。

## 实际操作

1. 选择「小屋副本」或「空白 16 × 12 × 16」，按「载入场景」。也可「导入鲸图」读 PNG / `.schem`。编辑的是工作台内存副本；不写游戏存档、房屋资源或 IndexedDB。切场景也是一步撤销。
2. 设置「编辑层 Y」，在网格上点选格子。北在上（−Z），东在右（+X），白色为空气，橙色为家具，蓝框为选中格。右侧拖动旋转 3D；「对准场景」重新框选整幅场景。「隐藏上层」只影响预览，导出的数据始终包含全部层。
3. 选「放方块」，从常用清单挑选木板、石砖、玻璃、楼梯、半砖等，也可直接输入完整状态，例如 `minecraft:oak_door[facing=east,half=lower,hinge=left,open=false,powered=false]`。修改 `half`、`axis`、`open` 等属性后，再点格或输入 XYZ 按「执行」。朝向下拉会修改已有的 `facing` 属性；没有该属性的方块仍按完整状态处理。
4. 「选择 / 吸取」读出目标的普通方块状态；点到家具会识别整件。普通方块可逐格删除。「用当前方块填本层空气」仅填空格、保留已占用格，整层只记一次撤销。
5. 选「摆整件家具」，挑家具与朝向，再点格。任意一部分都能选中整件；「家具转 90°」绕主格旋转，「将选中家具移到 XYZ 输入坐标」将主格移到所填坐标并采用当前朝向。移动前先选中原家具，填目标坐标后直接按移动，勿先按「执行」改变选中格。
6. 删除家具的任意部分会删除整件，不能用普通方块覆盖半件。放置/移动/旋转若越界或撞到其他非空气格，会整步拒绝；已导入的不完整家具可清除，但不能继续移动/旋转。
7. 「撤销 / 重做」保留最近 80 步，包括场景载入、导入、填层、家具操作。在网格或面板上按 Ctrl/Cmd+Z 撤销、Ctrl/Cmd+Shift+Z 重做；正在文本框输入时保留浏览器的文字撤销。
8. 按「导出鲸图 PNG」下载当前视角的 PNG 预览和完整场景数据。相册、照片框的原有照片数据随家具移动，PNG 再导入后仍在；单格原版方块仅修改同 id 的状态时保留箱子/告示牌等 BE。换成不同 id 或删除时才移除该格 BE。

切回其他工作台模型会释放编辑器 UI、网格与预览资源；再回编辑器继续当前副本及撤销历史。刷新页面会丢失未导出的编辑。无效/取消的文件导入不会清空当前副本。

## 范围与约束

- 坐标为鲸图内部格子，范围从 0 到各轴尺寸减 1；保留导入模型的 offset、metadata、dataVersion 及未改动方块实体。`RequiredMods` 使用原有 share 导出逻辑重新计算。
- 最多导入 262144 格；空场景尺寸固定为 16×12×16。暂不提供扩展边界或批量框选。
- 方块状态输入校验格式与重复属性，不替代 MC 注册表校验。手写门的上下半格、原版多格植物等需自行搭配；家具的多格由清单统一管理。
- 创作模式允许悬空；需要在 MC 中存活的灯笼、照片框等请补支撑。地图格子是定位/选色视图，右侧使用现有 MC grid 渲染器、模组资源和自绘近似纹理；已选本机 MC jar 时复用其材质。
- 这里保留和显示已有相册/照片框的照片；上传、编辑相册内容仍使用现有相册功能。不会另建照片格式。

## 复用与模块边界

`src/46-block-editor.js` 提供纯数据操作与独立模型/面板；`src/46-block-editor.css` 只控制本编辑器。`build.mjs` 在 cabin/home 中排除 46 模块，studio 自动包含。未修改通用反馈 UI。

复用 `13-share` 的 canonical schema、索引、读写 PNG 与 NBT；`44-furn-mc` 的 41 类家具所有朝向、part 与占格；`45-photos` 的 BE/slot 数据；`55-photo-frames` 的照片纹理缓存；`43-house-mc-model` 的层裁切、网格生成与释放；`54-house-mc` 的资源包。照片叠加复制共享纹理后独立释放，旧异步渲染和切换离开后的导入不会写回当前编辑器。

## 测试和 MC 交接

在 `web` 目录运行纯数据测试：

```bash
npm run test:editor
```

173 项覆盖 41 类家具×4 朝向的整件放置/移动/删除、不可覆盖半件、碰撞失败不改数据、同 id 改状态保留原版 BE、照片 NBT、畸形导入家具、撤销/重做/分支、填层和 PNG 往返。

真实浏览器检查需要已构建的 studio 和共享静态服务（不要与其他成员同时 build）。例如先由负责构建的人运行 `node build.mjs studio` 并让现有服务提供 `dist`，再运行：

```bash
npm run test:editor -- --url http://127.0.0.1:5194/studio.html
```

此命令复用现有服务，不自行 build 或启动服务。它通过真实 Edge 点网格删除/键盘撤销，选场景、放方块、放床/旋转/重做、移动带照片的框；验证无效导入无损、PNG 导出/导入、真实文件输入导入、照片渲染、切模型释放，以及零 pageerror。临时产物位于仓库根：

- `tmp/recovery-20261109/editor/workbench-edited.png`：编辑后鲸图。
- `tmp/recovery-20261109/editor/workbench-edited.json`：导出解码后的逐格/BE 基准。

`mod/cards/P6-001.yml` 使用上述产物：复制 PNG 到 probe 测试目录，MC place 后拍照片框近景与全景，再 capture 上次，通过 `expect_files` 比对所有格子、状态、offset 和照片 BE。场景体积 3072 格、非空气 265 格，含木板地面、双 half 的 east 门、east 床、north 望远镜、一张实图的相册矮桌及移动后 south 照片框。卡片加载解析已通过；MC 运行由 lead 统一调度，本编辑器测试不会启动 MC 或写用户游戏。
